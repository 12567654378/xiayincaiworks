顺从还是反抗？国内主流大语言模型的双重对齐研究

选取 DeepSeek-V3、Qwen3.6-plus、Ernie-4.5-Turbo 三个国内主流大模型，聚焦高价彩礼、数字复活、算法困境三大本土争议议题。构建"价值-话语"双维分析框架，设计五级梯度提示词，通过 API 接口批量获取语料数据，完成大模型对齐表现的实证考察。研究成果在人工智能与平台经济论坛等4个高水平学术会议汇报，获第十届网络空间治理与传媒法治建设论坛暨"何微新闻奖"研究生论坛二等奖。

科研论文 · 内容分析

抖音平台新农人自我呈现研究——基于240条抖音短视频的内容分析

以抖音短视频平台80个新农人账号的240条视频为样本，采用内容分析法与案例研究法，探究新农人媒介形象的自我呈现特征与策略。研究发现，新农人以中青年为主力，广泛分布于农业大省，通过个人信息展示、视频内容创作构建多元形象，既包括真实质朴的乡土叙事者、乡土文化守望者、数字创业者等正面形象，也存在媒介素养匮乏、价值导向跑偏等负面类型。其自我呈现策略涵盖情感共振、价值升华、前台身份隐匿与人设符号建构四大维度。这些发现丰富了"新农人"媒介形象的研究，并为助力优化"新农人"媒介形象的自我呈现提供实践参考。

调研报告 · 案例分析

阅文集团经营模式调研报告

在数字化与全球化背景下，网络文学成为中华文化国际传播的重要载体。阅文集团作为中国网络文学行业的领军企业，自诞生起便在行业中占据着主导地位。基于阅文上市以来的年报、行业报告以及政策文件，采用案例分析、文本分析、数据比较等方法，辅以深度访谈，分析其经营模式。发现阅文集团拥有"在线阅读+版权运营"二元盈利结构，且构建了 IP 价值链，通过内部驱动与全球化拓展，实现了 IP 价值的放大，成为了中国故事出海的标杆。尽管其经营仍面临免费阅读冲击、文化折扣、IP 改编高风险等挑战，但阅文集团的实践表明，构建 IP 全价值链生态、前瞻性应用新技术以及坚持本地化共创，是媒介企业在全球化时代实现商业成功与文化传播的有效路径。
